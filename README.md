> My sensors are calibrated for everything except you — every reading just says 'stay'.

## Why the joke works

A robot's whole identity is precise measurement: its sensors are calibrated to read the world exactly. The joke turns that precision against itself — the one thing it cannot measure is the person standing in front of it, and every reading collapses into a single, helpless word. There is no human pickup line with robot words pasted on top; the charm comes from the machine failing at its own job in the most sincere way possible. It is a line a robot could deliver with total confidence, and one a reader could repeat to someone else the same day.

## Run it

```bash
python3 main.py
```

This writes the pickup line to `/output/entry.txt` (or the directory named by `MAKEFUN_OUTPUT_DIR`).
